# Avisos de terceiros

O WinPlay inclui código e bibliotecas de terceiros. A distribuição do projeto é feita sob GPL-3.0; os componentes mantêm suas licenças e os avisos aplicáveis.

| Componente | Licença / aviso |
| --- | --- |
| DiPlay e código derivado de xcertplay | GPL-3.0; procedência em `UPSTREAM.txt` |
| JNA | Avisos em `licenses/JNA-LICENSE.txt` |
| Bouncy Castle | `licenses/Bouncy-Castle-LICENSE.txt` |
| FFmpeg | Textos GPL/LGPL em `licenses/`; configuração e distribuição em `UPSTREAM.txt` |
| JavaCPP | `licenses/JavaCPP-LICENSE.txt` |
| JmDNS | Apache-2.0 |
| SLF4J | `licenses/SLF4J-LICENSE.txt` |
| FlatLaf | Apache-2.0 |
| JUnit e Hamcrest | Avisos em `licenses/` |

Consulte [UPSTREAM.txt](UPSTREAM.txt) para versões, origens, adaptações e condições de redistribuição, e [LICENSE](LICENSE) para o texto principal da licença. Os manifestos `UPSTREAM-SHA256.csv` e `DEPENDENCIES.sha256` ajudam a verificar os arquivos distribuídos.

O material importado para autenticação não faz parte deste repositório e não é relicenciado como código do WinPlay. Sua origem e verificação são descritas nos avisos de procedência.

O nome de um commit identifica quem preparou aquela alteração; não substitui os créditos e direitos sobre componentes incorporados.
